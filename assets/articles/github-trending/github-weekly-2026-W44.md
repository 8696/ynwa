## 数据方法

- **窗口**：2026-10-26..2026-11-01 UTC 闭区间；来源 `python3 ~/.hermes/skills/gh-trending-watch/scripts/windows.py --route weekly --format env`（`WEEKLY_CREATED`）。周档由每周一 CST 08:40 的 cron 自动触发。
- **排序**：GitHub Search API `created:2026-10-26..2026-11-01 archived:false (ai OR llm OR agent OR mcp OR assistant) in:readme` + `sort=stars&order=desc&per_page=50`，匿名调用（本期跑前校验 `ghp_` classic PAT 仍返回 **401 Bad credentials**，已回退匿名 60/h；core 配额用尽后 README 改走 `api.github.com/repos/{owner}/{repo}/readme` 拉取）。
- **过滤**：`scripts/rank.py` 自动剔除空壳 / 擦边仓；本期 raw 50 条全部保留，无剔除。
- **口径披露（本期重要）**：`in:readme` 是**子串级**匹配，会命中 README 中任何位置的 ai/agent 等词，而非只命中「项目是 AI 产品」。实测确认两类情况：① **真命中但非 AI 产品**——[valentderah/totk-pc-recomp](https://github.com/valentderah/totk-pc-recomp) 命中原因仅是 README 末句「written by AI coding agents (Claude Code)」；[kevinraymond/florilegium](https://github.com/kevinraymond/florilegium) 是「made with the assistance of AI (Claude)」；[Humpalumps/Ultra-Water](https://github.com/Humpalumps/Ultra-Water) 是「argued out with a second agent」；[arpanjot-coding/AVault](https://github.com/arpanjot-coding/AVault) 是「1-Prompt 自动化安装 via AI Assistants」。② **AI 相关但非 AI 产品**——[physicsdolphin/nv-uefi-unlocker](https://github.com/physicsdolphin/nv-uefi-unlocker) 的 README 确实以「你的 GeForce 正以半速跑 AI」开篇，LLM 推理 prefill +19% 是其核心卖点，属真命中。已用 API 逐仓拉 README 核对上述五仓的命中上下文。读者可据此判断：榜内约 8–9 席（#5、#11、#25、#27、#28、#30 等）是「AI 参与开发 / 顺带提及」而非 AI 题材项目。
- **对比**：`rank.py --write` 写入本期快照（`data/snapshots/weekly--2026-10-26..2026-11-01.json`）。上期快照为 `weekly--2026-10-12..2026-10-18.json`（W42）——**W43（2026-10-19..2026-10-25）快照缺失，本期对比直接跨到 W42**。因口径是「窗口内新创建仓库」，两期仓集天然不重叠，30 仓全部新上、star_delta 无可比对项；表内 Δ 列取自 2026-10 月榜快照的同仓对比（仅 3 仓有交集）。
- **slug**：`github-weekly-2026-W44`；db.json 顶层 tags 复用既有 `github-weekly-ranking`。
