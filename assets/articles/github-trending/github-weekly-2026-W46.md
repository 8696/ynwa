- **窗口**：2026-11-09..2026-11-15 UTC 闭区间；来源 `python3 ~/.hermes/skills/gh-trending-watch/scripts/windows.py --route weekly --format env`（`WEEKLY_CREATED`）。周档由每周一 CST 08:40 的 cron 自动触发。
- **排序**：GitHub Search API `created:2026-11-09..2026-11-15 archived:false (ai OR llm OR agent OR mcp OR assistant) in:readme` + `sort=stars&order=desc&per_page=50`。本期跑前校验 `~/.private/gh-trending-token` 里的 classic PAT 仍返回 **401 Bad credentials**（连续第 3 期），已回退匿名 60/h；core 配额在深挖阶段用尽，后续 issue 改走 `search/issues` 端点（独立配额）补齐。
